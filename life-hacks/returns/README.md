# 网购退货 8 个真相

双11快到了,下单前先把这篇存着。

北京市市场监管局今年5月公布过一个案例:有人网购了个吹风机,拆开检查后对外观不满意,申请七天无理由退货,商家说“已拆封影响二次销售”,不给退。
其实条例写得挺清楚,为了查验拆包装、合理调试,没影响原有品质功能和外观的,商家应当退。

我把相关法规原文翻了一遍,整理成8条:七天从哪天算、哪些本来就不退、什么才算完好、运费谁出、被拒了怎么办……每页底下都标了出处,跟商家沟通的时候可以直接对着条文说。

几个提醒:
平台自己的规则有时比法规更宽,以你下单页面写的为准;
线下实体店和买的服务(课程、会员这些)不适用七天无理由;
七天无理由也不是怎么都能退,别故意弄坏东西再退。
拿不准的可以直接打12315问。

依据:《消费者权益保护法》《消费者权益保护法实施条例》《网络购买商品七日无理由退货暂行办法》,案例来自北京市市场监督管理局官网。
