# 年休假 8 个真相

一到年底,身边总有人问:今年的年假没休完,是不是能拿 3 倍工资?

翻了一下《企业职工带薪年休假实施办法》第十条,原文写的是按日工资的 300% 支付,"其中包含用人单位支付职工正常工作期间的工资收入"。
也就是说那天的正常工资本来就照发,额外补的是日工资的 200%,不是在工资之外再拿 3 倍。苏州市人社局的政策问答里也是这么解释的。

顺手把年假相关的条文都过了一遍,整理成 8 条:
工作多久才有、5/10/15 天怎么定、哪些假不占年假、300% 怎么算、日工资公式、自己书面说不休会怎样、年中入职和离职怎么折算。
每页底下都标了条文出处,算的时候可以直接对着看。

几个提醒:
本篇按企业职工写,机关事业单位另有规定;
公司规定比法定标准更好的,按公司的来;
年休假条例已经在推动修订,以官方最新文本为准;
自己的情况拿不准,可以打 12333 问当地人社。

依据:《职工带薪年休假条例》《企业职工带薪年休假实施办法》,均来自中国政府网。
